🔍 Test Tìm Phim trên TMDB

Gõ tên phim bất kỳ → xem TMDB trả về kết quả gì (Minions, Avatar, Batman, phim Việt...)
Nếu bạn đã có key thật (từ themoviedb.org/settings/api), dán vào đây để test. Bấm Kiểm tra key xem key có hợp lệ không.
Hướng dẫn:
1. Bấm Tìm kiếm — app gọi thẳng TMDB /search/multi từ trình duyệt.
2. Nếu thấy Kết quả: N phim → key hoạt động, search TMDB OK. Nếu thấy status_message → key sai/hết quota, thay key khác.
3. Bấm vào poster → mở trang TMDB của phim đó.
4. Ghi chú: TMDB API hỗ trợ CORS nên chạy trực tiếp từ trình duyệt được — app CHRTV dùng cách y hệt thế này.
