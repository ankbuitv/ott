📦 Bản APK

com.chrtvplay.appCHRTV PL▷Y 1.0.0 beta

Máy build trong workspace không tải được Android SDK (chặn mạng tới dl.google.com), nên APK phải build trên GitHub Actions. Workflow đã được sửa lại đầy đủ, chỉ còn thiếu 1 bước bấm tay vì token bot không có quyền ghi file trong .github/workflows.

  1. Mở repo → file .github/workflows/build-android.yml → nút bút chì.
  2. Xoá hết, dán nội dung file ci/build-android.yml trong repo.
  3. Commit thẳng vào nhánh arena/01a0759f-ott.
  4. Tab Actions → chờ ~10 phút → tải artifact chrtv-apk.
